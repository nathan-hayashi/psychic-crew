# DIVE-W1-EK-1, explained plainly

## What this gate is

The web lane opens: a dated re-verification sweep over the ~30 ecosystem rows RSCH-2 flagged
[Ekn] (known-from-knowledge, never web-verified) and the six PARK revisit conditions — has
anything materially changed since 2026-08-26? This is currency-checking, not mechanism
hunting: the prediction on record is TAKE-ZERO, and re-verification is the sworn
prerequisite before any row could ever promote to INCORPORATE.

## What the token buys

Read-only dated web fetches under the PROGRAM-OPEN ruling scope (git/API contribution stays
barred), a dive doc whose read manifest lists every URL with its retrieval date, verdicts
the validator binds, and register/queue/map moved atomically.
